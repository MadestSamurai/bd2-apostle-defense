# BD2 Apostle Defense v0.3.8

## 简体中文

### 更新内容

- 50波目标采用分阶段决策：前10波优先刷7/8阶核心，保留基础产金阵容。未形成核心且开启自动续局时重开；本局后停止和中途接管晚期对局不自动放弃。
- 有核心后集中培养暗、水及高阶补位，停止为低阶杂色分散升级。结合后续五波与下一首领预留升级金币，避免一够召唤费用就花掉、迟迟存不到核心升级费用。
- 低压力时回收低贡献杂色的金币；暗水阵容缺少高阶补位时，每个安全波次最多补抽两次。保留有价值的5/6阶第三属性补位，避免只升级单一核心而缺少后期输出。
- 重开沿用游戏的退出、确认和返回大厅流程，暂停或对局变化后撤销旧指令。

### 下载

适用于 Windows x64。两版功能相同，均为单 EXE，内置简体中文／English。

| 版本 | 运行环境 | 建议 |
| --- | --- | --- |
| **Portable** | 内置 .NET 运行时 | 首次使用推荐，下载即用 |
| **Lite** | 需安装 .NET Desktop Runtime 8 x64 | 已安装运行时，下载更小 |

下载一种版本即可。ZIP 附中英文说明和许可证；SHA256SUMS.txt 可用于核对下载文件。

### 升级

暂停并关闭旧工具，再打开新版连接；本机设置保留。当前组件支持在游戏保持运行时更新和交接；如游戏本身仍显示断线或登录提示，请先恢复游戏连接。

[使用说明与风险声明](https://github.com/MadestSamurai/bd2-apostle-defense/blob/main/README.md)

## English

### Changes

- The wave-50 goal uses staged decisions: prioritize a tier-7/8 core during the first ten waves while retaining basic earners. With auto-next enabled, an opening without a core restarts. Stop-after-round and late attachment prevent automatic abandonment.
- Once a core is present, upgrades focus on dark, water and a high-tier support element. Gold is reserved against the next five waves and the next boss, so repeated affordable summons cannot starve core upgrades.
- Recycle low-contribution off-colour units under low pressure. When the Water/Dark complement is missing, allow at most two extra rolls per safe wave. Useful tier-5/6 units can fill the third element, avoiding a lone core without late-game support.
- Restarts use native Exit, confirmation and lobby flow. Pausing or changing rounds revokes old restart commands.

### Downloads

For Windows x64. Both editions have the same features, run as a single EXE and include Simplified Chinese / English.

| Edition | Runtime requirement | Recommended for |
| --- | --- | --- |
| **Portable** | .NET included | Most users; download and run |
| **Lite** | .NET Desktop Runtime 8 x64 required | Smaller download if the runtime is installed |

Download one edition. ZIPs include both READMEs and licenses. Use SHA256SUMS.txt to verify downloaded files.

### Upgrade

Pause and close the old assistant, then connect with the new version. Local settings are retained. Current components support updates and handoff while the game stays open. If the game itself is disconnected or asking you to log in, restore its connection first.

[Usage and risk disclaimer](https://github.com/MadestSamurai/bd2-apostle-defense/blob/main/README.en.md)
