BrownDust II Windows 客户端的独立使徒运气防守辅助工具，面向「通关第50波」与「累计召唤最高级使徒」两个成就。实时读取盘面和游戏规则，自动召唤、升级、换位、重抽，以及结算后继续下一局。内置简体中文／English，无需 Python 或其他 BD2 工具。

## 下载与使用

当前版本 **0.2.1**。两种版本功能和语言完全相同：

| 版本 | 运行环境 | 建议 |
| --- | --- | --- |
| Portable | 内置 .NET 运行时 | 首次使用推荐，直接双击 EXE |
| Lite | 需安装 .NET Desktop Runtime 8 x64 | 下载较小，适合已安装运行时的电脑 |

EXE 可单独运行；ZIP 还包含中英文说明、许可证和维护文档。只需下载一种版本。可使用发布页的 `SHA256SUMS.txt` 校验下载。

1. 升级前暂停并关闭旧工具，正常重启游戏，让旧组件退出。
2. 进入使徒运气防守大厅，打开助手，点击「连接游戏」。
3. 选择目标，核对账号与服务器进度，点击「开启自动化」。默认先争取50波通关，完成后转向最高级使徒召唤。
4. 随时可暂停；也可勾选「本局结算后停止」。暂停工具不会暂停游戏计时。

顶部可即时切换简体中文／English。首次跟随系统语言，之后记住选择；切换语言不改变当前任务、间隔或待执行命令。游戏提供的名称保持原语言。

从0.2.0升级到0.2.1：暂停并关闭旧助手，正常重启游戏，再打开新EXE连接。此次修复位于工具侧决策，但不同发布构建的组件身份校验仍要求重新连接新的游戏会话。

## 盘面与策略

- 68格盘面按真实位置绘制，显示属性与阶数、敌人、移动箭头；点击使徒查看属性、射程和路线覆盖。点击只查看信息，不操作游戏。方向键可选格，Esc取消。
- 英文格内使用 Wa／Fi／Wi／Li／Da 表示水／火／风／光／暗，后接阶数。完整名称在点选详情和悬停提示中显示。
- 普通波比较可执行移动／交换的净收益，并考虑升级、召唤和低风险重抽。出售成功后优先补回空位。
- 首个首领前先补足3名使徒；不足召唤费用时留钱，不抢先升级。基础阵容齐备后，升级按当前波实际所需攻击次数评估，不给过量伤害虚计清怪收益；金币不足下一抽时，还需能通过新增击杀更快赚回召唤费用。该模型用于决策估计，不是完整战斗模拟。
- 首领波根据实际敌人位置、速度与路线进行短时间预测，自动移动主力追击；支持多首领，计算交换对象的输出损失，并保留攻击进度。首领波暂停静态搬位与卖出重抽。
- 操作间隔100–3000ms，默认500ms；每条命令等待游戏回读确认，不堆积操作。首领追击另外校验目标存活、波次和快照时效。
- 自动完成原生退出／确认／返回大厅，回读服务器成就后决定是否续局。关闭自动续局仍会处理本局结算退出。

策略使用短时间收益估计，**不是完整战斗模拟器，也不保证通关50波或召唤到指定使徒**。动态追击已做离线对照，实机效果仍会受阵容、帧率与延迟影响。

## 连接、兼容与诊断

- 仅支持 Windows x64 的 PC 客户端，一次只连接一个游戏进程。进入对应小游戏后连接；其他弹窗可能使操作等待。
- 组件在连接时根据本机程序集接口生成；可识别的改名和重排由兼容层处理，无法可靠匹配时停止连接。跨版本适配不代表保证所有未来版本可用。
- 程序不包含游戏 DLL、账号凭据、库存、回放或私有采集文件；游戏规则从本机读取。
- 配置、语言及诊断位于 `%LOCALAPPDATA%\BD2ApostleDefense`，界面可打开。旧私有版本设置继续沿用。诊断可能包含账号名称、盘面及本地路径，反馈前请自行删去个人信息。
- 长时间没有心跳时检查游戏是否已退出、仍在加载、或加载了旧组件；更换工具版本后正常重启游戏再连接。
