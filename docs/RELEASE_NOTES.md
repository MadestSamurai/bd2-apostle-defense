## 中文

0.2.1：修复开局反复升级、始终招不出第二名使徒的问题。

- 开局优先补足3名使徒，保护下一次召唤的资金。
- 前期升级按当前波击杀所需攻击次数评估，一击已能击杀时不再为过量伤害浪费金币；兼顾紧邻下一波，避免过早为后期首领投资。
- 金币不足召唤时，只有能更快赚回下一抽费用的有效升级才可插入；召唤收益考虑后续移动到合适空位。
- 修复中英文README里被免责声明损坏的第三方许可链接。
- 保留原设置和双语。升级时暂停并关闭旧助手，正常重启游戏，再打开新EXE连接。

## English

0.2.1 fixes opening upgrade loops that could prevent summoning even a second unit.

- Build a three-unit starting lineup and preserve gold for summons.
- Early upgrades use current-wave hits to kill, so overkill does not count as faster clearing. The adjacent wave matters without prioritizing distant bosses over survival.
- While saving for a summon, an upgrade must earn that summon back sooner. Summon value includes moving the new unit to a suitable empty tile.
- Repair third-party license links corrupted by disclaimer text in both READMEs.
- Existing settings and both languages are retained. Pause and close the old assistant, restart the game normally, then connect with the new EXE.

| Edition | Runtime | Download choice |
| --- | --- | --- |
| Portable | .NET included | Recommended for most users |
| Lite | Requires .NET Desktop Runtime 8 x64 | Smaller download |

Both editions include the same features and languages, a standalone EXE and a ZIP with both READMEs. SHA256 checksums are provided. Using an assistant carries risks including account penalties; assess and accept those risks yourself. See the disclaimer at the top of the README.
