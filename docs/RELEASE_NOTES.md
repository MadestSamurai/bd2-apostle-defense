## 中文

首次独立开源发布，MIT，内置简体中文／English即时切换。

- 通关50波／最高级使徒双目标，服务器成就确认与自动续局。
- 清晰68格盘面、射程检查、自动召唤／升级／交换／重抽。
- BOSS动态追击，支持多首领并计算交换损失。
- 保留旧设置；升级前暂停关闭旧工具并正常重启游戏。

| 版本 | 运行时 | 下载 |
| --- | --- | --- |
| Portable | 自带.NET | 首次使用推荐 |
| Lite | 需.NET Desktop Runtime 8 x64 | 体积更小 |

两版功能和语言一致，均提供独立EXE与附中英说明的ZIP，另有SHA256校验文件。使用辅助工具存在账号处罚等风险，请自行评估并承担使用后果；详见README顶部声明。

## English

First standalone open-source release, MIT licensed, with live Chinese / English switching.

- Wave-50 and top-tier-summon goals, server-confirmed achievements and automatic next rounds.
- Readable 68-cell board, range inspection, summons, upgrades, swaps and rerolls.
- Dynamic boss pursuit with multiple-target support and swap-loss accounting.
- Existing settings are retained. Pause and close the old assistant, then restart the game before upgrading.

| Edition | Runtime | Download choice |
| --- | --- | --- |
| Portable | .NET included | Recommended for most users |
| Lite | Requires .NET Desktop Runtime 8 x64 | Smaller download |

Both editions include the same features and languages, a standalone EXE and a ZIP with both READMEs. SHA256 checksums are provided. Using an assistant carries risks including account penalties; assess and accept those risks yourself. See the disclaimer at the top of the README.
